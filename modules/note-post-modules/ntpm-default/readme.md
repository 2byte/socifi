# Note post module

Это шаблонный модуль, который позволяет создавать интерактивные посты внутри заметок. Модуль построен на компонентной системе vue3 и может содержать различные типы контента, такие как текст, изображения, видео и интерактивные элементы.

На основе данного модуля разрабатываются модули постов заметок (note posts), которые могут быть подключены к заметкам и использоваться для создания интерактивных приложений внутри заметок.
